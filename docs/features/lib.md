## What it does
This module provides utility functions and interfaces for interacting with the API, handling authentication, and displaying toasts.

## Where it lives in the UI
N/A

## Key flows
- Use `req<T>` to make API requests with different HTTP methods.
- Use `getToken` to get the authentication token.
- Use `setAuth` to set a new authentication token and user information.
- Use `clearAuth` to clear the authentication token and user information.
- Use `getUser` to retrieve the authenticated user.
- Use `showToast` to display toasts of different types.
