This module provides utility functions for making API requests. It includes functions to clear authentication, get an authentication token, and set authentication for user data.

N/A

## Key flows
1. Clear authentication by calling `clearAuth()`.
2. Get the user's authentication token by calling `getToken()`.
3. Set the user's authentication data by calling `setAuth(token, user)`.
