## What it does
This module provides utility functions for API requests, authentication, and toast notifications.

## Where it lives in the UI
N/A

## Key flows
1. **Authentication**: Fetch a token from `localStorage` and use it in API requests.
2. **API Requests**: Make HTTP requests using the `req` function.
3. **Toast Notifications**: Display notifications of different types using the `showToast` function.
