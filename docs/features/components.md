## What it does
The components directory contains client-side UI components for various parts of the application.

## Where it lives in the UI
- N/A

## Key flows
1. Navigate to the application's main dashboard.
2. Use the sidebar to navigate to different sections.
3. Fill out forms such as login and onboard.
4. View and interact with KPI cards.
5. View PDF documents.
6. Select filters or categories using pill tabs.
